## 🚀 Featured Project

### GitHub Profile Analyzer

[![Live Demo](https://img.shields.io/badge/Live_Demo-https://github--profile--analyzer--1--rbv7.onrender.com-4BC0C0?style=for-the-badge&logo=render&logoColor=white)](https://github-profile-analyzer-1-rbv7.onrender.com)

A full-stack analytics tool that:
- 📊 **Rates GitHub profiles** with tier-based scoring (0-100)
- 💡 **Generates personalized suggestions** for improvement
- 📈 **Visualizes activity** and language distribution
- 🔗 **Exports data** as JSON

**Tech Stack:** Node.js, Express, GitHub API, Chart.js, MySQL, HTML/CSS

**Why I built it:** To understand how data flows from API → Backend → Frontend and to practice building a complete project from scratch.
